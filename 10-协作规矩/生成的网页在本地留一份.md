# 生成的网页在本地留一份

## 要怎么做

- 通过 Artifacts 生成的 HTML，都在本地保留一份。发布用的源文件本来就是本地文件，放在项目里对应的文档目录，发布后它就是本地这一份。
- 文档、说明里给出的链接指向本地 HTML 文件，优先用相对链接。
- 不要把 claude.ai 上 artifact 的私有链接当作主链接。
- 私有链接仍要记下来（记在 agent 的记忆或发布记录里），以后更新那个 artifact 时要用。记下来不等于拿它当主链接。
- 项目如果有同步副本的惯例，本地这份一并同步过去。

## 为什么

claude.ai 上 artifact 的链接是私有的，要登录作者的账号，或者经过分享，才能打开。本地 HTML 双击就能看，离线可用，还跟着项目和它的副本一起走。

依据类型：本人要求。

## 什么时候适用，什么时候不适用

- 适用：用 Claude 的 Artifacts 生成 HTML 的时候。

## 例子

- 不合格：说明文档里写「图解见」，后面跟一个 claude.ai 的私有链接，别人点开要登录。
- 合格：说明文档用相对链接指向项目里的 HTML 文件；私有链接只记在发布记录里，备更新用。
