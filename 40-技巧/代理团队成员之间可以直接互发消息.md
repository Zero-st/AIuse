# 代理团队成员之间可以直接互发消息

**做法**：做「多个 agent 互相通信」时，直接用 Claude Code 原生的代理团队（Agent Teams）：

- 主会话当 Team Lead，负责生成队友、分配任务、汇总。
- 在每个队友的提示词里告诉它其他队友的名字，并约定握手协议，比如后端写完直接 SendMessage 给前端传接口契约。
- 让队友点对点交流。不要去改 agent 的 tools 配置，也不必由主 agent 全程居中转发。

**为什么**：在代理团队里，队友 agent 的 Mailbox 点对点通信是团队级能力，不受它自己定义文件里 `tools` 白名单的限制。即使两个队友的 `tools` 只列了 `Read,Grep,Glob,Edit,Write,Bash`、没列 SendMessage，它们作为命名队友被生成后，照样能直接给其他队友发消息：mailbox 即时送达，可以点发，也可以广播。

agent 曾以为 tools 白名单没列 SendMessage 就不能发消息，于是想去改 agent 配置，或者让主 agent 居中转发，这是绕远路。我纠正它时讲的是：Agent Teams 由四部分组成，Team Lead 协调；队友各自独立上下文；共享 Task List（pending/in_progress/completed，可设依赖）；Mailbox 点对点和广播通信。
