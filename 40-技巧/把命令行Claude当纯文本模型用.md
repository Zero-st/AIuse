# 把命令行 Claude 当纯文本模型用

**做法**：写小工具、做隔离测试，需要它只读输入、只回文字时，用这一组参数：

```bash
claude -p --model opus --effort medium --system-prompt "<自己的系统提示词>" \
  --tools "" --safe-mode --strict-mcp-config --disable-slash-commands \
  --no-session-persistence \
  --output-format stream-json --include-partial-messages --verbose
```

另外三件事要一起做，缺一样隔离就不干净：

- 输入从标准输入送。
- 工作目录用一个空目录。
- 启动之前去掉环境里所有名字以 `CLAUDE` 开头的变量。从 Claude Code 的终端里启动子进程时，会带下来十几个。

最后一行的三个参数是要流式输出时才需要的。只要最终文字的话可以去掉，标准输出就是回答全文。

**为什么**：不做隔离时，个人的规则文件、记忆、技能列表都会被带进提示词，既花 token，又让结果受个人配置影响。同一句话的输入，隔离后是 692 token，不隔离是 3277 token。隔离后，初始化信息里的工具、外部服务、技能、斜杠命令四项全为空，也不会留下新的会话记录。

实测环境：2026-11-17，Claude Code 2.1.321。2026-11-23 在同一版本上又用去掉流式三个参数的写法跑了 5 次隔离问答，全部正常。升级后先用一句最短的输入验证这组参数还认，再用。

依据类型：真实运行（2026-11-17 实测；2026-11-23 复用 5 次）。

**什么时候用，什么时候不用**：

- 用：把它嵌进脚本当文本处理器；想知道「一个什么都不知道的模型」读了某份材料会怎么答。
- 不用：任务需要读写文件、跑命令或用到项目上下文时。那是它带工具的正常用法。

**几个容易踩的地方**：

- 用订阅登录可以，不需要 API 密钥。但 `--bare` 这个参数不行，它只认 API 密钥。
- `--safe-mode` 换成 `--setting-sources ""` 效果一样，输入都是 692 token。
- 隔离之后，初始化信息里仍会显示个人设置的输出样式名，但样式的内容没有进提示词，不影响结果。
- 流式输出时，文字在 `stream_event` 事件的 `event.delta.text` 里；最后一条 `result` 事件带用量、耗时和回答全文。
- 一次约 3800 token 系统提示词的改写任务，耗时 7～19 秒，3～8 秒出首字。
