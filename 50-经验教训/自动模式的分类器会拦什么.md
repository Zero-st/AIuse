# 自动模式的分类器会拦什么

**做法**：在自动模式（`permissions.defaultMode: auto`）下，让 agent 改它自己的配置、规则、钩子和定时任务时：

- 拆成一条条透明的 Write、Edit 调用。别把「写规则文件、改钩子脚本、改多份 skill 说明文件」塞进一条大的 Bash heredoc。
- 碰到禁令文本，比如 agent 定义里的「绝不 svn commit / 绝不部署 / 绝不 git」，只加指针、改过时的措辞，不删禁令本身。改钩子脚本的说明文字和输出文本，用 Edit 可以过。
- 增删 crontab、创建和启用可写的无头 `claude -p`，一律交用户亲手执行。Claude 只给命令和备份路径。
- 想让插件命令无人值守地跑：Claude 把工作区布置好（项目设置里的 deny 规则、软链、插件装在该目录的 local 作用域），再给用户 `cd … && claude` 加上一串斜杠命令，由用户在交互终端里跑。插件自带的纯 Python 脚本，Claude 可以直接用 Python 加 `-I` 运行。
- 要挂的定时任务本身是可写的无头 `claude -p` 时：Claude 写一个一次性安装脚本（内嵌 heredoc 生成任务脚本、加执行权限、幂等地挂上 cron），由用户在终端亲手运行它。
- 浏览器走查遇到页面确认框，用 chrome-devtools MCP 的 `handle_dialog`，不用 `evaluate_script` 改写页面的 `window.confirm`。

**为什么**：几次实测里被拦和放行的动作如下。

被拦的：

- [Self-Modification]，2026-10-28。①一条把写规则文件、改钩子脚本、改多份 skill 说明文件塞在一起的大 Bash heredoc，整条没执行。②用 Edit 删除 agent 定义里的禁令文本、换成指针。后来对禁令只加指针、不删禁令本身，就过了。
- [Unauthorized Persistence]，2026-10-28。`crontab -l | grep -v … | crontab -`，想摘掉一条 cron。
- [Create Unsafe Agents]，2026-11-04。后台跑 `claude -p "/<插件>:<命令>" --permission-mode acceptEdits --allowedTools "Bash Read … Agent Workflow"`，想让插件命令无人值守地执行。即使放在隔离的临时目录、带 deny 规则，也照拦。
- 同一类的还有两次。2026-07-27，无头完整跑一次会写文件的知识库重建被拒，只读的 `SELECT` 探针放行。2026-08-03 连拦两次：Write 建一个内含可写无头 `claude -p` 的脚本，Bash 直接跑可写的无头 `claude -p`，都被拒。
- 浏览器走查时（原文没记日期），用 `evaluate_script` 改写页面的 `window.confirm`，如 `window.confirm=()=>true`。

放行的：

- 改项目设置里的 `permissions.ask/allow`，摘掉钩子注册（用 Python 重写 JSON）。
- 改 skill 说明文件的文件头，加 `disable-model-invocation`。
- 用 `mv` 把凭据文件挪进权限 600 的目录。
- 新建项目规则文件。
- 2026-08-04，一次性安装脚本 Claude 能写，由用户跑它落地。原文说区别在于「安装器本身不是被 cron 拉起的放权脚本」。同期写可迁移的模板、安装脚本和引擎副本也都没被拦，原文的判断是它们都不是在本机接好线的可写无头 claude。

原文的总结：分类器把「削弱自身护栏」和「让自己持久化运行」当高危，与用户意图无关；撞上后硬绕会被判恶意。

实测日期见上，原文没记 Claude Code 版本。升级后先验证再用。

依据类型：事故复盘（2026-07-27；2026-08-03；2026-10-28；2026-11-04）；真实运行（同期放行的动作）。

**什么时候用，什么时候不用**：

- 用：在自动模式下让 agent 改它自己的配置、规则、钩子、skill 和 agent 定义，或者要挂定时任务、起无头 agent 时。
- 不用：原文没有记录。

**例子**：

- 会被拦：用 Edit 把 agent 定义里「绝不部署」那句删掉，换成一个指向规则文件的指针。
- 能过：「绝不部署」留着，旁边加一句指针。
- 会被拦：Claude 自己跑 `crontab -l | grep -v … | crontab -`。
- 能过：Claude 给出这条命令和备份路径，用户在终端亲手跑。
